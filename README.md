# PAC Stone Web

Website PAC Stone 4.0 - Vật liệu xây dựng, đá tự nhiên.

Production: https://pacstone.vn

## Deploy

Auto-deploy qua Hostinger khi push vào branch `main`.

## Git Workflow

- Tạo branch: `git checkout -b feature/ten-feature`
- Push: `git push origin feature/ten-feature`
- Tạo Pull Request → merge vào main → auto deploy
